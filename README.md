This is a demo Client Tracker for a Coach. Base includes:
- Tables: Applications (populated from the base's Form), Client Tracker (for Approved/Paid Clients), Coaches (To Assign to Approved Clients)
- Automations: Populate Applications table, Update Application Status (approve or reject), notify Clients via Mail, notify Coaches in Slack, Update Amount Paid in Clients and Coaches Tables
- Interfaces (Dynamic Dashboard to monitor and analyze Clients, Coaches and Payments data)
- Forms: Application form for Clients to sign up.
